## Coherent original direction

Use one dominant language: **vermilion, ink and warm paper**, derived from the majority of the collection. Suggested original tokens are scarlet `#f52b37`, ink `#101011`, warm white `#f4f0e6`, and a restrained pale yellow `#f4e779` for selection/focus. These are design proposals, not measured samples of the anniversary website.

Use oversized condensed display typography, restrained editorial serif accents, narrow uppercase interface labels, offset baselines, and deliberate angular panel edges. Keep body copy straight, readable, and quiet. A personal `KM` identity or original masked/abstract figure would provide a distinctive focal point without falsely identifying a supplied stranger as the owner.

Halftone screens can be generated with CSS radial gradients on limited decorative areas. Original outlined stars, skewed paper strips and cutout shadows can be authored in SVG/CSS. The hero should be a large typographic composition; projects should become differently composed spreads with original technical graphics. No stock illustration or identical rectangular project card system is necessary.

Suggested adaptation by section:

- Hero: oversized name, original monogram/emblem, diagonal profession strip and a clear project action.
- Profile: two-column editorial dossier, muted halftone background and selected factual highlights.
- Projects: one feature story per project with distinct technical diagram/mock interface and an expandable case file.
- Experience/education: angular timeline or menu rows, never arbitrary fabricated ability scores.
- Skills: category selection with readable technology labels and restrained active-state movement.
- Contact: poster-scale invitation, strong public professional links and accessible resume action.
