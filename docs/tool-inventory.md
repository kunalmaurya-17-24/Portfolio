# Capability discovery

Inspected the enabled tool catalog and skill catalog before implementation. No existing app, dependency manifest, or AGENTS.md was found in the workspace or checked ancestor locations.

Relevant capabilities used: PowerShell/filesystem tools; multi-agent orchestration (three parallel research/content/technical agents); CUA in-app browser with DOM snapshots, computed-style inspection, screenshots, viewport control and real clicks; Node/npm and TypeScript; bundled Playwright, sharp, Python, pypdf/reportlab and Poppler; actual local-image viewing; web access for primary-source evidence. The installed system Edge browser supports independent automated QA.

Available broader connectors include Sites, GitHub, Notion, Pages/Spaces, document control, LinkedIn, Pets, plugin management, app/thread/worktree/automation management, artifact editing, web search, image generation and REA browser/binary analysis. Those unrelated services were not connected to or mutated for this local portfolio. Image generation is unnecessary because the commissioned graphic language can be implemented as original SVG/CSS. No PDF/slides/spreadsheet authoring service is needed beyond the public resume PDF.

Skills read/applied: Sites (local workflow, presentation-led design and preview guidance), PDF (complete extraction and visual verification), computer-use (browser/native workflow). Skills for deployments, pets, documents, wiki management and spreadsheet tasks were assessed as irrelevant. No external posting, deployment or paid service was performed.

Agents: resume/content analysis + sanitized PDF; complete image inventory and creative direction; architecture/browser capability investigation + original audio system. Independent visual and technical review follows implementation.
