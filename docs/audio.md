# Audio configuration

The player ships with **After Hours / Original instrumental**, a sample-free, original procedural instrumental generated by `src/audio.ts`. Warm synth chords, bass and sparse percussion are scheduled through Web Audio at 82 BPM. It contains no Persona recording, melody, transcription or third-party sample. No supplied audio file was found in the project. This fallback gives the interface functioning audio without redistributing game music.

Audio starts only when a visitor explicitly presses Play. Preferences preserve volume and mute state, never autoplay consent. Mute and playback are separate states. Master gain ramps soften starts, pauses and mute changes. Switching browser tabs pauses playback, and returning never restarts it automatically. The soundtrack is optional and every portfolio feature works silently.

## Use an authorized track

1. Put an audio file you are authorized to redistribute in `public/audio/`.
2. Edit `public/audio/track.json`:

```json
{
  "src": "/audio/your-authorized-track.mp3",
  "title": "The actual track title",
  "artist": "The actual artist",
  "license": "Your permission or license details"
}
```

3. Rebuild the site. Verify the file URL and player in the production preview.

Set `src` to `null` to restore the original instrumental. The JSON is optional and invalid or missing configuration falls back safely. A supplied HTTP(S) URL can stream authorized audio, but local assets avoid external availability issues. The track is chosen when the visitor first presses Play; changing the JSON requires a page reload. Displayed track information is plain text, never HTML.

Possession of a Persona recording does not establish permission to redistribute it on a public portfolio. No unauthorized game audio was downloaded. Add an official permitted embed only after confirming its terms; an embed's controls and playback restrictions should remain intact.

## UI integration

Call `initAudio()` after rendering the player. Its return value cleans up listeners, pending requests, timers and audio resources. The module expects these IDs:

- `audio-player`: root; receives `data-playing`, `data-muted` and `data-source` state.
- `audio-toggle`: native button; its accessible label and pressed state update automatically. Optional `[data-audio-label]` child receives PLAY/PAUSE.
- `[data-audio-icon]` inside the toggle receives the matching play/pause glyph and should be hidden from assistive technology.
- `audio-mute`: native button; optional `[data-mute-label]` child receives MUTE/UNMUTE.
- `audio-volume`: labelled range input, minimum 0, maximum 100.
- `audio-title`: actual track name/artist.
- `audio-status`: playback status. Use `aria-live="polite"`.

Decorative equalizer movement should depend on `[data-playing="true"]` and be disabled by the global reduced-motion stylesheet. The audio engine does not animate DOM elements.

## Browser behavior and evidence

Web Audio is created/resumed inside the explicit Play handler, following browser user-gesture expectations. [MDN autoplay guide](https://developer.mozilla.org/en-US/docs/Web/Media/Guides/Autoplay)

The default synthesizer uses oscillators and a deterministic generated noise buffer. An authorized file uses a looping `HTMLAudioElement` with smooth volume ramps and no preload. This avoids downloading a track before consent. [Web Audio best practices](https://developer.mozilla.org/en-US/docs/Web/API/Web_Audio_API/Best_practices)

Failures leave a retryable audio control and readable status. localStorage is optional; privacy-mode storage errors do not break the app. No background audio scheduling continues after a completed pause. Actual browser validation results are recorded separately in the project's QA documentation.

Isolated module validation on 25 November 2026 passed in real headless Edge through bundled Playwright: silent initial state, original synth Play/Pause, file Play/Pause using a generated original QA tone, Mute/Unmute, volume changes, persisted preferences without autoplay, immediate background pause, resource disposal and zero uncaught page errors. `tsc --noEmit` also passed. The development-only harness is `tmp/audio-qa.mjs`; its tone is generated in memory and never included in production.
